# 理想汽车事故线索智能分配平台 - 详细设计文档

## 一、项目背景与业务价值

### 1.1 项目背景

理想汽车作为中国新能源汽车领军企业，目前拥有130万车主，全国200多家直营店，未来主要通过授权店扩张。随着保有量的快速增长，事故车线索的高效分配成为提升客户体验和优化网络运营的关键。

目前面临的核心挑战：
- **线索分配不统一**：多渠道线索（保险系统、400客服、车机、APP）缺乏统一分配机制
- **人工干预频繁**：线索分配依赖人工判断，效率低下且容易产生偏差
- **门店负载不均**：部分门店线索过多，部分门店线索不足，资源利用不均衡
- **客户体验不一致**：缺乏考虑客户意愿和便利性的分配机制
- **管理抓手缺失**：无法通过线索分配引导门店提升服务质量和运营效率

### 1.2 业务价值

智能分配平台将为理想汽车带来的核心价值：
- **提升客户体验**：通过智能分配，确保客户就近、高效获得服务，满意度提升25%+
- **优化网络运营**：实现门店负载均衡，资源利用率提升40%+
- **强化管理抓手**：通过线索分配机制引导门店提升服务质量，形成良性竞争
- **降低运营成本**：减少人工干预，提高处理效率，运营成本降低30%+
- **支持网络扩张**：为未来授权店模式提供标准化的线索分配机制，支持网络快速扩张

## 三、技术架构设计

### 3.1 前端技术栈

- **框架**: React 18 + TypeScript

- **UI组件库**: Ant Design 5.x
- **地图组件**: 高德地图 API
- **图表库**: ECharts 5.x
- **路由**: React Router 6
- **样式**: Styled Components + CSS Modules
- **构建工具**: Vite

## 四、UI/UX设计规范

### 4.1 设计原则

- **简洁明了**: 界面简洁，信息层次清晰
- **数据驱动**: 以数据为中心，突出关键指标
- **响应式设计**: 适配不同屏幕尺寸
- **一致性**: 保持设计语言和交互的一致性
- **可访问性**: 支持键盘导航和屏幕阅读器

### 4.2 色彩规范

- **主色调**: 理想蓝 (#1890FF)
- **辅助色**: 成功绿 (#52C41A)、警告橙 (#FAAD14)、错误红 (#F5222D)
- **中性色**: 文本黑 (#262626)、次要文本 (#8C8C8C)、背景灰 (#F5F5F5)

### 4.3 组件规范

- **卡片**: 圆角8px，阴影2px
- **按钮**: 主按钮高度40px，次按钮高度32px
- **表格**: 斑马纹背景，悬停高亮
- **图表**: 统一配色方案，支持主题切换

```typescript
interface Lead {

  priority: number;
}
```

```typescript
interface Store {
```

```typescript
interface AllocationModel {
  id: string;
  name: string;
  version: string;

    regions: string[];
    cities: string[];
  };
  status: 'DRAFT' | 'TESTING' | 'APPROVED' | 'ACTIVE' | 'DEPRECATED';
  createdAt: string;
  updatedAt: string;
}
```

### 5.2 API接口设计

#### 5.2.1 线索管理
- `GET /api/leads` - 获取线索列表
- `POST /api/leads` - 创建新线索
- `PUT /api/leads/:id` - 更新线索信息
- `POST /api/leads/:id/allocate` - 分配线索

#### 5.2.2 模型管理
- `GET /api/models` - 获取模型列表
- `POST /api/models` - 创建新模型
- `PUT /api/models/:id` - 更新模型
- `POST /api/models/:id/test` - 测试模型
- `POST /api/models/:id/approve` - 审批模型

#### 5.2.3 数据分析
- `GET /api/analytics/dashboard` - 获取仪表盘数据
- `GET /api/analytics/performance` - 获取绩效数据
- `GET /api/analytics/trends` - 获取趋势数据

## 六、演示场景设计

### 6.1 场景一：区域管理人员配置分配模型

**功能流程**：
1. 登录系统，进入"模型管理中心"
2. 创建新模型，选择"距离+绩效模型"
3. 配置模型参数和适用范围
4. 保存并提交审批

**关键交互**：
- 参数配置界面支持实时预览
- 模型保存时进行参数验证
- 审批流程状态实时更新

### 6.2 场景二：线索实时分配

**功能流程**：
1. 系统接收新线索
2. 调用分配模型进行计算
3. 展示分配结果和推荐理由
4. 客户确认分配结果

**关键交互**：
- 实时展示分配计算过程
- 地图可视化分配结果
- 支持客户反馈和重新分配

### 6.3 场景三：数据分析与优化

**功能流程**：
1. 查看多维度数据分析
2. 识别优化机会
3. 创建模型新版本
4. 测试和对比效果

**关键交互**：
- 交互式图表和地图
- 支持数据筛选和钻取
- 模型对比分析功能
